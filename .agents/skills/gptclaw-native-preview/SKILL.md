name: gptclaw-native-preview
description: Prepare, build, inspect and install a private Android native preview through an existing local or EAS project contract. Use for preview artifacts, not store submission or production promotion.
---

Read the project's actual build and preview contract, including tool pins,
artifact access, selected profile and existing authorization. Use
[the preview checklist](references/preview.md) for upload, identity and installation
checks. The skill provides no build service or credentials. Missing setup does
not block independent archive inspection or local source checks.

Choose the fastest supported artifact path that enables the requested working
journey. Reuse an exact suitable artifact rather than rebuilding it unnecessarily.
Honor authorized cloud submission; preparing a preview alone does not authorize
source upload, signing credential creation, store publication or production work.
Track one build ID and reconcile unknown outcomes before resubmission.

Keep source checks, CI, artifact inspection, installation and observed native
journey separate in [the preview record](assets/preview.md). An APK that builds
successfully is not proof of working sign-in, recording or persistence.
