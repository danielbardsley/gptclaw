# Android development client architecture

The native storage probe demonstrates a module beyond Expo Go using synthetic
MMKV values that are removed after each check. Android is the supported build
target. Generated native directories are owned by Prebuild; no handwritten native
source is adopted automatically. JavaScript edits use owned private Metro.

The bound notes variant deliberately retains its typed notes API, synthetic CRUD
and native notebook; it uses a separate FastAPI/PostgreSQL project. Neither source
quality nor a successful cloud build establishes installation or device acceptance.
