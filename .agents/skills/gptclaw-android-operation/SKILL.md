name: gptclaw-android-operation
description: Operate an existing Android emulator or device for native application testing, upgrades, UI inspection and bounded diagnostics. Use for Android execution, not emulator provisioning or host repair.
---

Resolve the project root, requested journey and existing Android operation contract.
Read [device procedures](references/device.md) for target selection, upgrade and
native interaction. Verify installed tooling rather than installing host packages.
An operation request authorizes its scoped reversible actions; preserve existing
authorization and do not ask again. Resolve ambiguous devices before mutation.

Use the exact APK and device identity, retain application data, and demonstrate
observable native outcomes. Start with the principal journey and the first actual
blocker. Capture only relevant private evidence; UI dumps and screenshots may
contain personal data. Bound waits and logs before collection. Missing capability
blocks its dependent action, not independent diagnosis or source work.

Report source/artifact/installed identity, exact actions and observed results using
[the observation outline](assets/observation.md). Synthetic emulator GPS and short
background checks cannot establish phone GPS, battery, locked-screen reliability
or accessibility qualification. Never mark an unexecuted interaction passed.
