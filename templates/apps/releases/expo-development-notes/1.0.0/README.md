# Android development-client starter

This opt-in starter uses SDK 57 and generated native source. Run the managed
source quality commands before explicit `native-build` planning/submission.
Build configuration and account approval are required; creation never starts
Metro, uploads source, creates accounts or submits a build. `build` still exports
JavaScript/assets. The native storage probe uses synthetic values in MMKV and
removes its test key. Backend notes are deliberately retained in the bound variant.
